Within MODE 1, we should have tables and graphics that display important information about crashes. We can discuss what these will be.
(FOR LATER) MODE 2, Risk Assessment. The user is able to visualize different ways of assessing risk on the roadways given certain specifications (we will define those later)
(FOR LATER) MODE 3, Predictive Modeling. The user is able to visualize results from a model we developed and see what is the probability of crashes occurring on a given road
